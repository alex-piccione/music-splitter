# Project Roadmap

## Phase 1: MVP (Minimum Viable Product)
*Goal: A working tool that splits an MP3 into defined segments.*
- [x] Functional User Interface (Tkinter/TTK)
- [ ] Core MP3 Splitting Engine
- [ ] Automated Output Organization (Folders per file)
- [ ] Configuration System (`config.txt`)

## Phase 2: Robustness & UX
*Goal: Make the tool reliable and easy to use.*
- [ ] Advanced Error Handling & Logging
- [ ] Batch Processing (Multiple files at once)
- [ ] Dark Mode / Theme Customization

## Phase 3: Expansion
*Goal: Broaden format support.*
- [ ] Support for `.wav` and other formats.
- [ ] Command Line Interface (CLI) mode.
